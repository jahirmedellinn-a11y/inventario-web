1. Requerimientos del Sistema

El proyecto consiste en una aplicación web interactiva desarrollada para la gestión y control de inventarios de artículos, implementando el ciclo completo de operaciones de datos (CRUD), persistencia en servidor de base de datos relacional y generación de reportes en hojas de cálculo.

1.1. Requerimientos Funcionales (RF)

Código Requerimiento Descripción detallada
RF-01 Visualización de Inicio Panel principal con navegación fluida, mensaje de bienvenida y desglose de módulos disponibles.
RF-02 Consulta de Catálogo Listado dinámico en tabla HTML de todos los productos almacenados en MySQL (ID, nombre, categoría, descripción, existencia).
RF-03 Registro de Productos Formulario para captura de nuevos artículos con validaciones en servidor (campos obligatorios y cantidad no negativa).
RF-04 Modificación de Artículos Edición de datos existentes mediante formulario precargado por ID, ejecutando sentencia UPDATE.
RF-05 Eliminación con Confirmación Borrado seguro de artículos (DELETE) con diálogo nativo de confirmación en JavaScript para evitar pérdidas accidentales.
RF-06 Generación de Reporte Excel Exportación descargable inmediata de la tabla a formato Microsoft Excel (.xls) con suma total y codificación UTF-8.

1.2. Requerimientos No Funcionales (RNF)

  • RNF-01 (Compatibilidad y Entorno): Ejecución local sobre pila XAMPP (Apache HTTP Server y MariaDB/MySQL).
  • RNF-02 (Persistencia y Robustez): Conexión mediante interfaz PHP Data Objects (PDO) con sentencias preparadas contra inyecciones SQL.
  • RNF-03 (Semántica y Estilos): Cumplimiento de estándares HTML5 (header, nav, main, footer, table, form) y estilos centralizados en CSS.
  • RNF-04 (Usabilidad y Soporte de Caracteres): Codificación integral en UTF-8 (soporte para acentos, letra ñ y caracteres en español).

4.5 Documentación de actividad ESTRUCTURA DE PÁGINA Diseño de Solución y Pseudocódigo

2. Diseño de Solución del Cliente

La solución se diseñó bajo una arquitectura cliente-servidor tradicional de dos capas web, donde el cliente interactúa mediante el navegador a través de peticiones HTTP/GET y HTTP/POST, y el servidor Apache interpreta los scripts PHP consultando la base de datos MySQL.

2.1. Estructura del Proyecto

Archivo Tipo Responsabilidad en el Sistema
conexion.php Backend / Config Instancia y gestión del objeto PDO conectado a la base de datos inventario_db.
index.php Vista Principal Interfaz de bienvenida y navegación institucional (respetando la maquetación original).
productos.php Vista / Controlador Consulta (SELECT) y despliegue del catálogo con botones de acción y exportación.
agregar.php Vista / Controlador Formulario de captura y procesamiento de inserción (INSERT) con validaciones.
editar.php Vista / Controlador Búsqueda por ID, carga de valores y guardado de modificaciones (UPDATE).
eliminar.php Controlador Ejecución de baja de registro (DELETE) y redirección con notificación.
exportar_excel.php Servicio de Reportes Construcción de hoja de cálculo MIME con cabeceras HTTP y marca BOM UTF-8.
style.css Estilos globales Reglas CSS institucionales para colores, reset, formularios, tablas y botones.

2.2. Diseño de Base de Datos (Modelo Relacional)

Base de datos: inventario_db | Tabla: productos (Cotejamiento: utf8mb4_unicode_ci)

CREATE TABLE productos ( id INT AUTO_INCREMENT PRIMARY KEY, nombre VARCHAR(150) NOT NULL, categoria VARCHAR(100) NOT NULL, descripcion TEXT NULL, cantidad INT NOT NULL DEFAULT 0, fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP ) ENGINE=InnoDB;

7. Manual de Usuario (Guía de Operación)

Paso 1: Puesta en Marcha del Servidor

1. Abra el panel de control XAMPP Control Panel.
2. Presione el botón Start en el módulo Apache y en el módulo MySQL (ambos deberán mostrarse en color verde).

Paso 2: Acceso a la Aplicación

Abra su navegador web e ingrese a la dirección: http://localhost/inventario-web/ o bien haga doble clic en el acceso directo ABRIR SISTEMA ubicado dentro de la carpeta del proyecto.

Paso 3: Navegación y Uso de Módulos

  • Consultar Inventario: Haga clic en la pestaña Productos para visualizar la lista completa con existencias.
  • Registrar Artículo: En la pestaña Agregar Producto, ingrese el nombre, categoría, descripción y cantidad, luego presione Guardar Producto.
  • Modificar Artículo: En la tabla de productos, presione el botón verde Modificar sobre el producto deseado, cambie los valores y haga clic en Guardar Cambios.
  • Eliminar Artículo: Presione el botón rojo Eliminar y confirme la pregunta en pantalla para remover el artículo.
  • Generar Reporte Excel: En la parte superior de la tabla de productos, presione el botón Exportar a Excel para descargar la hoja de cálculo.
